# Dicey Home v0.1.0

Released 2026-11-04. The first alpha baseline, before the notification center.

## Highlights

- Native **Dicey Home** dashboard inside the Omarchy launcher (Ctrl+Shift+F):
  activity, MPRIS media, output volume, a focus timer and session actions.
- Browser-default web search in the themed command palette.
- Opt-in development copies (`scripts/dev.py`) kept separate from the installed
  production plugin.
- Dashboard internals grouped under `home/`; portable test entry points retained.
- Bar widget plugin identity and Qt theme-color qualification fixed.
- Upstream notices, release tooling and marketplace preparation docs.

## Notes

- Alpha software: `0.x` versions may change behavior between releases.
- `omarchy plugin update` follows the default branch, not tags; see
  [publishing](../publishing.md) for rollback to this tag.
